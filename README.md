# SAKSHI WEBSITE

A static scrapbook-style personal website for Sakshi.

## Soundtrack

The built-in player defaults to **Elvis Presley — Can't Help Falling in Love** and attempts to start around the selected song's memorable section rather than at 0:00. Use the queue button (☰) to switch songs. Each track has its own configured starting point.

Browsers may block automatic audio playback until the visitor interacts with the page. If that happens, the first tap/click/keypress starts playback.

Audio files are stored locally under `assets/music/`.
